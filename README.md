# AgriVision: Crop Maturity AI

A learning project exploring computer vision for
tomato maturity classification and harvest-time prediction.

## Current milestone

Binary tomato maturity classification:
- Green / unripe
- Ripe

## Tech stack

- Python
- PyTorch
- OpenCV
- scikit-learn

## Dataset

Ripe and Unripe Tomatoes Dataset from Kaggle.

Dataset files are not included in this repository.
See the project instructions for downloading the data.
